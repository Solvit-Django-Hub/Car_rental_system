# Car Rental Management System

A web-based **Car Rental Management System** built with **Python and Django**.
The system is designed to make it easier for users to view available cars, rent vehicles, and manage rental information.

## Features

* User registration and login
* View available cars
* View car details
* Rent a car
* Manage rental information
* Admin dashboard
* Add, update, and delete cars
* Track car availability

## Technologies Used

* Python
* Django
* HTML
* CSS
* JavaScript
* Postgres
